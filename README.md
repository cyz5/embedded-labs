# embedded-labs

嵌入式课程配套练习仓库。每个目录对应能力地图里的一个技能点编号，
课程正文在 <https://cyz5.github.io/>。

> 这个仓库目前只有目录骨架，**没有任何练习代码**。后续由我按课程进度逐个填写。

## 目录约定

```text
labs/<章节>/<技能点编号>/
```

例如：

- 课程：https://cyz5.github.io/p/1-1-1/
- 练习：`labs/01-c/1.1.1/`

目录名就是技能点编号，和课程 URL、能力地图一一对应，不需要额外映射表。

## 怎么开始一个练习

1. 在 [INDEX.md](INDEX.md) 里找到要做的技能点；
2. 进入对应目录，自己决定代码结构（可以放 `src/`、`tests/`、`README.md`）；
3. 提交并推送：

```bash
git add -A
git commit -m "feat(1.1.1): 多级指针与函数指针"
git push
```
